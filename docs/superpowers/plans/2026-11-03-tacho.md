# Tacho Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tacho, an open-source native macOS menu bar app that reads coding CLIs' local logs and shows the live token consumption rate, per-source and per-category breakdowns, API-equivalent cost, quota projections, an activity log and heatmaps.

**Architecture:** One SwiftPM package. `TachoKit` (library) holds everything testable: one reader per CLI that turns on-disk records into `UsageEvent`s and `QuotaSnapshot`s, a GRDB store, an ingest actor (backfill + FSEvents tailing), pricing, metrics and projections, and an `Engine` actor that returns ready-to-render view state. `Tacho` (SwiftUI `MenuBarExtra` + one window) only renders `Engine` output; `tacho-cli` prints the same numbers for smoke tests and reconciliation. Rates are SQL queries over the store, run once a second; there is no separate in-memory window.

**Tech Stack:** Swift 6 (tools 6.0, language mode 6), SwiftUI, Swift Charts, Swift Testing, GRDB.swift 7.12+, facebook/zstd 1.5.7 (`libzstd`), FSEvents, ServiceManagement.

**Spec:** `docs/superpowers/specs/2026-11-03-tacho-design.md` (Chinese). Read it before any task; `§` references point into it. Reference implementation for parsing rules (TypeScript, MIT, same author): `~/projects/glassbox` — files listed in the spec's appendix.

## Global Constraints

- `platforms: [.macOS(.v14)]`, `swift-tools-version: 6.0`. Code must also compile with the Swift 6.0/6.1 toolchains on GitHub's macOS runners: no language features newer than Swift 6.0.
- Dependencies: only `https://github.com/groue/GRDB.swift` `from: "7.12.0"` (product `GRDB`) and `https://github.com/facebook/zstd` `from: "1.5.7"` (product `libzstd`). Argument parsing in `tacho-cli` is hand-written.
- Read-only toward every CLI directory; never write under them. Never open `~/.codex/auth.json`, `~/.claude/.credentials.json`, `~/.grok/auth.json`, `~/.pi/agent/auth.json`, `~/.local/share/opencode/auth.json`, `~/.gemini/oauth_creds.json`, or any table in `~/.omp/agent/agent.db` other than `cache`.
- Never store, log or print conversation content, prompts, tool arguments, file contents, tokens or keys. Per event, only the `UsageEvent` fields are stored.
- No network except the opt-in Anthropic usage request (§5.6). No telemetry, no update checks.
- Token categories are disjoint: `total = input + output + cacheRead + cacheWrite5m + cacheWrite1h`; `output` includes reasoning; `reasoning` is for display only.
- Fixed values: rate window 60 s; series of 60 wall-clock minute buckets (newest partial); generation speed counts only output ≥ 50 tokens and duration ≥ 0.5 s; projection recent window 1800 s; snapshot stale after 900 s (5-hour) / 3600 s (weekly); icon red at estimated use ≥ 90%; backfill reads files modified within 7 days first; quota files polled every 30 s; Anthropic fetch every 300 s; FSEvents latency 0.5 s; full rescan every 60 s; a source is "active" if its last event is within 300 s.
- Bundle id `io.github.gogy717.tacho`; app name `Tacho`; MIT license, "Copyright (c) 2026 gogy717".
- UI languages: English (`en`, development language) and Simplified Chinese (`zh-Hans`); every user-visible string lives in both `Localizable.strings` files.
- Menu bar default: per-minute rate, compact (`12.4k/min`).
- Tests use Swift Testing (`import Testing`, `@Test`, `#expect`); run with `swift test`. Each test file declares one suite type named after the file (`struct LineReaderTests { @Test func … }`) so `swift test --filter LineReaderTests` selects it.

## Review Focus

1. A JSONL line far larger than the read chunk (Claude `api-request-blob` lines reach megabytes) is read whole, never split or dropped — `readsLinesLargerThanTheChunk` in Task 3.
2. A line caught half-written and completed on the next write counts exactly once — `readsCompleteLinesAndHoldsPartialTail` in Task 3 and `startTimeSurvivesChunkBoundary` in Task 4.
3. "Today", day cells and hour-of-week cells follow the user's local calendar, including half-hour UTC offsets and DST changes — `dayBucketsFollowLocalCalendar` and `hourOfWeekAcrossDST` in Task 11.
4. A session file deleted by its CLI (Claude Code prunes old transcripts) keeps its events in Tacho's history — `deletedFilesKeepTheirEvents` in Task 12.
5. A CLI that is not installed, or writes lines Tacho does not recognize, is reported (not detected / skipped count) and never stops ingestion — `countsUnparseableLinesAsSkipped` in Task 4 and `missingRootIsNotDetected` in Task 12.

  public struct FileCursor: Codable, Equatable, Sendable {
    public var inode: UInt64; public var size: UInt64; public var offset: UInt64; public var mtime: Date

    public var complete: Bool      // immutable file fully read (.zst)

  public enum LineReader {
    public static let defaultChunkSize = 4 * 1024 * 1024
    /// Calls `line` for every complete, non-empty line after the cursor; a trailing line without "\n" is left for the next read.
    /// Restarts from 0 (restarted = true, state = nil) when the inode changed or the file is shorter than the offset.

    var source: Source { get }
    func discover(root: URL) throws -> [URL]
    func read(_ url: URL, from cursor: FileCursor?) throws -> ReadResult

  struct JSONObject {                // internal
    init?(_ data: Data)              // top-level object only
    init(_ dict: [String: Any])
    func string(_ path: String...) -> String?; func int(_ path: String...) -> Int?; func double(_ path: String...) -> Double?
    func bool(_ path: String...) -> Bool?; func object(_ path: String...) -> JSONObject?; func array(_ path: String...) -> [Any]?
    func date(_ path: String...) -> Date?   // ISO-8601 with 0–6 fractional digits and Z or ±hh:mm; numbers: ≥ 1e11 epoch ms, else epoch s

  func dataContains(_ data: Data, _ needle: StaticString) -> Bool   // memmem-based prefilter
